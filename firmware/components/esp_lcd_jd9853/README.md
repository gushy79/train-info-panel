# esp_lcd_jd9853

Vendored, unmodified, from Espressif's JD9853 panel driver as distributed in
Waveshare's official ESP32-C6-Touch-LCD-1.47 demo package
(`https://files.waveshare.com/wiki/ESP32-C6-Touch-LCD-1.47/ESP32-C6-Touch-LCD-1.47-Demo.zip`,
`ESP-IDF/03_lvgl_example/components/esp_lcd_jd9853/`).

Licensed Apache-2.0 by Espressif Systems (Shanghai) CO LTD — see the SPDX header in
`esp_lcd_jd9853.c`. This is generic `esp_lcd` panel-driver code for the JD9853
controller, not Waveshare-specific or board-specific; board wiring/pin
configuration lives in `main/display/` instead.
